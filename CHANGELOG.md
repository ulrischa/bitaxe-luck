# Changelog

## 0.1.1

- Publish the reviewed custom integration with English documentation, dashboard examples, a local brand icon and HACS custom-repository metadata.
- Accept legacy formatted difficulties and devices exposing board information instead of ASICModel.
- Validate hostnames, HTTP URLs and ports; reject embedded credentials, query strings and API paths.
- Preserve entity identifiers when reconfiguring devices with host-based identity.
- Require an actual boolean pause state for mining control.
- Add regression tests and a Home Assistant compatibility workflow.
- Explain cumulative-work estimates, session limitations and the distinction between luck and block probability.
